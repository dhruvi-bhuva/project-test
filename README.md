# EventHub Automation Testing Project

## Project Overview
This project performs automated testing of the EventHub web application using Playwright and JavaScript.

## Website
https://eventhub.rahulshettyacademy.com/

## Technologies Used
- Playwright Test
- JavaScript
- Node.js
- Chromium

## Black-Box Testing Techniques
1. Equivalence Partitioning
2. Boundary Value Analysis

## Test Cases
- Login page verification
- Login form validation
- Registration page verification
- Email input testing
- Password boundary testing
- Home, Events, and Bookings page navigation

## How to Run
1. Install Node.js.
2. Run `npm install`.
3. Run `npx playwright install chromium`.
4. Run `npx playwright test --workers=1`.
5. Run `npx playwright show-report`.
